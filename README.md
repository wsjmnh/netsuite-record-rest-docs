# NetSuite Record REST API catalog (2026.1)

Factual Markdown catalog of the **NetSuite Record REST API v1** surface published for release **2026.1**. It lists record tags, HTTP operations, parameters, and schema property names/types extracted from the official REST API Browser. It is **not** an Oracle document and is **not** a substitute for the browser or account-specific metadata.

## Source

- Official REST API Browser (Record API v1, 2026.1): [https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2026.1/index.html)
- Operations are relative to `https://{accountId}.suitetalk.api.netsuite.com/services/rest/record/v1`

This catalog was generated by concatenating the Spectacle HTML chunks (`chunks/data00.part` … `chunks/data27.part`) linked from that index page and parsing tag panels, operation panels, and schema definition panels. Oracle/Spectacle help paragraphs are not copied; summaries are the original one-line operation titles from the browser.

## Layout

| Path | Contents |
| --- | --- |
| [docs/overview.md](docs/overview.md) | Base path, collection vs instance vs sublist, shared query/header parameters, `nsError` |
| [docs/records/README.md](docs/records/README.md) | A–Z index of every parsed record tag |
| [docs/records/account.md](docs/records/account.md) (and every other tag id) | One page per record: methods, parameters that appear, schema refs, sublists |
| [docs/schemas/README.md](docs/schemas/README.md) | Index of schema definitions |
| [docs/schemas/account.md](docs/schemas/account.md) (grouped by owning record; shared `ns*` in [ns.md](docs/schemas/ns.md)) | Property tables |
| [docs/coverage.md](docs/coverage.md) | Parse counts and gaps |

Filenames match the browser tag / definition id (for example `account`, `accountingBook`).
